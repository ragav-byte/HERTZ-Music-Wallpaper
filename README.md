# Muse

Muse is a music-inspired live wallpaper for Android that turns the colors of your current song artwork into a fluid gradient background.

## What it does

- Reads the current playing song title, artist, duration, and album art from the active media session on your phone
- Builds a fluid moving gradient from the dominant colors in the cover art
- Freezes the motion automatically when the song is paused
- Lets you tune the cover card size, radius, blur, text size, and card position

## Privacy

We can assure that Muse does not collect, upload, or sell sensitive personal data.

The app works locally on your device and only uses:

- notification access to read active media metadata from your current player
- wallpaper access to render the live wallpaper

No account login, remote analytics, or cloud sync is required for the core wallpaper experience.

## Install the APK

1. Copy the generated APK file to your mobile.
2. Install it using APKMirror Installer.
3. Open Muse.
4. Enable media access if Android asks for it.
5. Tap `Set wallpaper` and choose `Muse Wallpaper`.

APK path after build:

`app/build/outputs/apk/debug/app-debug.apk`
